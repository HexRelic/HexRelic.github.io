Rather not add a repository? Every app is also on its GitHub releases page and in Obtainium. All three install the same file, signed with the same key, so you can switch later without reinstalling.

How an app gets to your phone.

Five steps, and at each one there's something you or your phone can check instead of taking anyone's word for it.

  1. Public source

    All the code of every app is on GitHub under the GNU GPL. Nothing is built from code you can't read.

  2. Reproducible build

    Building a release from its source gives exactly the same file, byte for byte. Each app explains how to compare.

  3. Signed by HexRelic

    HexRelic signs each app with its own key, and publishes that key's certificate next to the source.

  4. Checked before listing

    The repository takes an app only if it carries that certificate, and signs its own index with a separate key.

  5. Checked on your phone

    Your client checks the repository fingerprint, and Android accepts an update only if it's signed with the same key as the app you have.

Questions.

What is an F-Droid repository?

A list of apps that an F-Droid client can install and keep up to date, a bit like a small app store. F-Droid, Droid-ify and Neo Store can follow several repositories at once, so adding this one doesn't change anything else you have.

Is this the main F-Droid repository?

No. The main repository is run by the F-Droid project. This is HexRelic's own, hosted on GitHub Pages, and it publishes the same signed files as each app's GitHub releases page.

What does the fingerprint protect against?

It identifies the key that signs the repository's list of apps. If someone handed you a copy of the repository, or changed it on the way, the fingerprint wouldn't match and your client would refuse it.

Can I switch between the repository, Obtainium and GitHub?

Yes. All three install the same file, signed with the same key, so Android sees the same app and updates it from whichever you use.

Do the apps collect anything?

No accounts, no ads, no analytics. Each app's privacy policy says exactly what happens to data: WitnessClip sends only a hash of the audio to get a certified time, and Scorch has no network permission at all.

Does this website track me?

No cookies and no analytics. Your theme and language choice stay in your browser. The site and the repository are hosted on GitHub Pages, and GitHub keeps its own server logs, including IP addresses, under the GitHub privacy statement.

Was AI used to make the apps?

HexRelic designs and develops the apps with large language models as assistants, to speed up development, testing and fixes. The apps themselves contain no AI.
